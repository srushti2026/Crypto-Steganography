## 🔐 What is VeilForge?

**VeilForge** is a full-stack steganography and cryptography platform designed to securely conceal sensitive information within digital media files.

The platform allows users to hide and retrieve confidential data from images, audio, video, and documents while preserving the appearance of the original file. In addition to traditional steganography, VeilForge also provides copyright watermarking and forensic metadata embedding for ownership protection and digital investigations.

---

## ✨ Key Features

* 🔒 **Secure Data Embedding** – Hide confidential information inside digital files
* 🔍 **Data Extraction** – Recover embedded content using the correct credentials
* 🖼️ **Multi-Format Support** – Works with images, audio, video, and documents
* ©️ **Copyright Watermarking** – Protect ownership of digital assets
* 🕵️ **Forensic Metadata Embedding** – Add traceable information for investigations
* 🤖 **PixelVault AI Integration** – AI-assisted image generation workflow
* 📊 **Interactive Dashboard** – Monitor and manage steganography operations
* ⚡ **Modern Web Interface** – Responsive and user-friendly experience

## 📽️ How It Works

1. **Upload a carrier file** (image, audio, video, or document).
2. **Select a module** such as General Protection, Copyright, or Forensic.
3. **Embed confidential information** using secure steganography techniques.
4. **Download the generated file** containing hidden data.
5. **Upload the modified file later** to extract the embedded information.
